## Challenge Structure

| Phase | Name | Description |
|---|---|---|
| Phase 1 | Secure the Environment | Connect to a preconfigured Skillable Microsoft 365 tenant and implement required security controls based on Secure Score recommendations. |
| Phase 2 | Security Hardening Plan | Create and submit a security hardening plan for a fictional Microsoft 365 customer environment. |

## Phase 1: Secure the Environment

Participants will connect to a preconfigured Skillable Microsoft 365 tenant and implement required security controls based on Secure Score recommendations.

The working control list includes:

- Enable multifactor authentication for all users in administrative roles
- Enable multifactor authentication for all users
- Block legacy authentication through Conditional Access
- Enable Microsoft Entra ID Identity Protection sign-in risk policies
- Enable Microsoft Entra ID Identity Protection user risk policies
- Prevent user consent to applications accessing company data on users’ behalf
- Automatically admit only invited users to Teams meetings
- Configure which users may present in Teams meetings
- Restrict anonymous users from joining meetings
- Use least-privileged administrative roles
- Set self-service password reset to all users

Controls may be adjusted if they cannot be reliably applied and validated during the exercise window.

Phase 1 is the qualification round. Participants who successfully complete Phase 1 advance to Phase 2.

## Phase 2: Security Hardening Plan

Qualified participants will create a security hardening plan for a fictional Microsoft 365 customer environment.

Your plan should explain:

- What should be implemented
- Why each recommendation matters
- What security risk each recommendation addresses
- How the recommendations improve the customer’s overall security posture

Each Phase 2 submission must include:

- Recommended Microsoft 365 security controls
- Explanation of why each control matters
- The security risk each recommendation addresses
- How the recommendations improve the customer’s security posture
- Clear organization and connection to the fictional customer scenario
- Proof that you completed the required AI Skills Navigator playlist

## Entry Limit

Each participant may submit **one entry**.

Attempts to submit multiple entries using different accounts, email addresses, identities, registrations, or logins may result in disqualification.

Automated participation is prohibited.

## Entry Requirements

To be eligible, your entry must meet the following requirements:

- Your entry must be your own original work.
- Your entry cannot have been selected as a winner in another contest.
- You must have all required consents, approvals, or licenses.
- Your entry must not violate the privacy, intellectual property, or other rights of any person or organization.
- Your entry must not include obscene, offensive, violent, defamatory, disparaging, illegal, or inappropriate content.
- Your entry must not include confidential information.
- Your entry must not include customer data, production tenant data, secrets, credentials, API keys, tokens, certificates, private keys, or connection strings.
- Your entry must not include offensive security tooling, malware, exploit code, persistence mechanisms, credential harvesting flows, or unauthorized scanning tooling.
- Your submission should demonstrate safe, responsible, and practical security improvement.
- You should be able to explain the recommendations in your own submission.

## Judging Criteria

Eligible entries will be judged using the following criteria:

| Weight | Criteria | What Judges Are Looking For |
|---:|---|---|
| 35% | Security Control Selection | Appropriate and relevant security controls for the customer scenario |
| 30% | Security Impact and Risk Reduction | Understanding of how the recommendations reduce meaningful security risks |
| 20% | Technical Understanding | Accurate explanation of what the controls do and why they matter |
| 15% | Quality of the Recommendation | A clear, well-structured plan tied to the customer scenario |

Winners will be selected within **30 days** after the entry period ends.
