5.	HOW TO ENTER

Challenge Structure

Phase	Name	Description
Phase 1	Secure the Environment	Participants connect to a preconfigured Skillable Microsoft 365 tenant and implement security controls based on Secure Score recommendations. An assessment script validates whether the required controls were successfully implemented.
Phase 2	Security Hardening Plan	Qualified participants create and submit a security hardening plan for a fictional Microsoft 365 customer environment.


How to Participate

1.	Register at https://aka.ms/defendthetenant (“Contest Website”)

2.	Complete the AI Skills Navigator playlist available at https://aka.ms/defend-the-tenant/playlist (“Playlist”) in AI Skills Navigator, available through the Contest Website.

3.	Join the Hackathon Kickoff [Optional]

4.	Complete Phase 1: Secure the Environment
Participants will connect to a preconfigured Skillable Microsoft 365 tenant and implement required security controls based on the tenant’s Secure Score recommendations. The working control list includes:
•	Enable multifactor authentication for all users in administrative roles
•	Enable multifactor authentication for all users
•	Block legacy authentication through Conditional Access
•	Enable Microsoft Entra ID Identity Protection sign-in risk policies
•	Enable Microsoft Entra ID Identity Protection user risk policies
•	Prevent user consent to applications accessing company data on users’ behalf
•	Automatically admit only invited users to Teams meetings
•	Configure which users may present in Teams meetings
•	Restrict anonymous users from joining meetings
•	Use least-privileged administrative roles
•	Set self-service password reset to All
Controls may be adjusted if they cannot be reliably applied and validated within the exercise window. Phase 1 is a qualification round. Participants who successfully complete Phase 1 advance to the Phase 2, the judged portion of the competition.

5.	Complete Phase 2: Security Hardening Plan
Qualified participants will create a security hardening plan for a fictional Microsoft 365 customer environment. The plan should explain:
•	What should be implemented
•	Why it matters
•	What security risk it addresses
•	How the recommendations improve the customer’s overall security posture
Each Phase 2 submission must include:
•	Recommended Microsoft 365 security controls
•	Explanation of why each control matters
•	The security risk each recommendation addresses
•	How the recommendations improve the customer’s security posture
•	Clear organization and connection to the fictional customer scenario
•	Proof that you have completed the Playlist, in accordance with Section 5(2) above

6.	After completing Phase 2, follow the instructions on the Contest Website to create a new GitHub Issue and submit your entry.
